# LR1_Torez

## Назначение проекта

Учебный многостраничный сайт о городе Торез, созданный в рамках лабораторной работы №1 по теме «Изучение HTML-тегов и CSS-стилей».

Проект предназначен для изучения структуры HTML5-документа, семантических тегов, CSS-стилей, позиционирования элементов, форм и других базовых средств веб-разработки.

## Использованные технологии

- HTML5
- CSS3
- PhpStorm
- Google Chrome
- Google Maps (встроенная карта через iframe)

Дополнительно на странице South Park персонажи и фон реализованы средствами HTML и CSS без использования изображений.

## Структура страниц

- `index.html` — главная страница с описанием города, фотогалереей и событиями.
- `history.html` — история города и таблица значимых событий.
- `infrastructure.html` — географическое положение, карта, административное устройство и транспорт.
- `culture.html` — информация о культуре, учреждениях и известных деятелях.
- `developer.html` — информация о разработчике и профессиональных навыках.
- `feedback.html` — форма обратной связи с HTML5-валидацией.
- `southpark.html` — усложнённое задание с персонажами South Park, нарисованными средствами HTML и CSS.
- `css/style.css` — основные стили сайта.
- `css/southpark.css` — стили страницы South Park.
- `images/` — изображения, используемые на сайте.

## Как запустить сайт локально

1. Открыть папку проекта в PhpStorm.
2. Открыть файл `index.html`.
3. Запустить его в браузере через **Open in Browser → Chrome**.
4. Переход между страницами осуществляется через навигационное меню.

Дополнительная установка библиотек или запуск отдельного сервера не требуется.
